# amulyaponnala.github.io

My personal site, live at [amulyaponnala.github.io](https://amulyaponnala.github.io).

It tells the story of three startups I have worked on before turning twenty: Pink Parcel, FemoraAI and Luna. It covers what each one taught me, what failed, and what is live now.

## Pages

- `index.html` is the main page: the three startups in order, then the things you won't find on my resume.
- `workflow/index.html` shows the outreach workflow we use to bring founders into Luna.

## How it's built

Plain HTML, CSS and a little JavaScript for the scroll reveals. No framework and no build step. GitHub Pages serves the `main` branch as is.

To run it locally, open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```
